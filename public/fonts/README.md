# Clash Display

Run `npm run fonts` to obtain the official, unmodified variable WOFF2 directly from [Fontshare](https://www.fontshare.com/fonts/clash-display). The installer checks the source hostname and WOFF2 signature. The file is used by `@font-face`, with `font-display: swap` and weights 200–700. It is not subsetted or converted.

The official download's [ITF Free Font License](LICENSE.txt), version 2.0 dated 17 August 2026, permits commercial use and self-hosting for the licensee's own website. Section 02 restricts redistribution through repositories and third-party font services. Therefore `ClashDisplay-Variable.woff2` is ignored by Git and each checkout/build downloads directly from the vendor. Keep the supplied license and use the font only within its terms. If the API changes, download from the official page and place its variable WOFF2 at this path. Avoid unverified mirrors.

Verified download and browser rendering: 7 October 2026. The earlier Phase 1 network limitation has been resolved in the current environment.
